# Glosario

| Término | Definición |
|---|---|
| 3CV | Comparación de calificaciones de al menos tres candidatos. Método del BID para seleccionar consultores individuales. |
| AAC | Autoridad de Aviación Civil de El Salvador. Regula la aviación civil y aprueba el protocolo de seguridad operacional de las obras del lado aire. |
| Acta de constitución | Documento que autoriza formalmente el proyecto y fija su propósito, objetivos, alcance general, interesados, restricciones, supuestos y responsable. |
| AIES | Aeropuerto Internacional de El Salvador San Óscar Arnulfo Romero y Galdámez. |
| BAC | Presupuesto hasta la conclusión (Budget at Completion). Total de la línea base de costos. |
| BID | Banco Interamericano de Desarrollo, financiador del programa. |
| BIM | Modelado de información de construcción (Building Information Modelling). |
| CEPA | Comisión Ejecutiva Portuaria Autónoma, organismo ejecutor del programa y operador del AIES. |
| Curva S | Representación del costo acumulado planificado a lo largo del tiempo. Su forma refleja un inicio lento, una aceleración y un cierre lento. |
| Día laborable (dl) | Día de lunes a viernes. Es la unidad de duración del cronograma. |
| EDGE | Certificación de edificación sostenible de la IFC (Excellence in Design for Greater Efficiencies). |
| EDT | Estructura de desglose del trabajo. Descomposición jerárquica del alcance en entregables, hasta los paquetes de trabajo. |
| Ex ante | Revisión previa del BID a cada paso de un proceso de adquisición, mediante su no objeción. |
| FIDIC amarillo | Modelo de contrato de la Federación Internacional de Ingenieros Consultores en el que el contratista diseña y construye. |
| Hito | Evento sin duración que marca un logro relevante del cronograma. |
| Holgura | Tiempo que una actividad puede atrasarse sin atrasar el fin del proyecto. |
| Línea base | Versión aprobada del alcance, el cronograma o los costos, que sirve de referencia para medir el desempeño. |
| LPI | Licitación pública internacional. |
| MEL | Plan de Monitoreo, Evaluación y Aprendizaje del programa. |
| No objeción | Conformidad del BID con un documento o decisión del organismo ejecutor. |
| Paquete de trabajo | Entregable del último nivel de la EDT, que se puede estimar, programar, asignar y controlar. |
| PEP | Plan de Ejecución del Proyecto, que reparte el programa y sus pagos en el tiempo. |
| PERT | Estimación por tres valores. La duración esperada es (O + 4M + P) / 6, con O optimista, M más probable y P pesimista. |
| PGAS | Plan de Gestión Ambiental y Social de las obras. |
| PMBOK | Guía de los Fundamentos para la Dirección de Proyectos del Project Management Institute. |
| PMR | Informe semestral de seguimiento del progreso que el organismo ejecutor presenta al BID. |
| POA | Plan Operativo Anual. |
| RACI | Matriz de asignación de responsabilidades que indica quién es responsable de la ejecución (R), quién aprueba (A), a quién se consulta (C) y a quién se informa (I). |
| Requisitos de financiamiento | Fondos que el proyecto necesita en cada periodo, calculados a partir de la línea base de costos y la reserva de gestión. |
| Reserva de contingencia | Monto o tiempo incluido en la línea base para los riesgos identificados. |
| Reserva de gestión | Monto fuera de la línea base para trabajo imprevisto dentro del alcance. |
| ROP | Reglamento Operativo del Programa. |
| Ruta crítica | Secuencia de actividades sin holgura que determina la duración total del proyecto. |
| SBCC | Selección basada en la calidad y el costo. |
| SBMC | Selección basada en el menor costo. |
| SCC | Selección basada en las calificaciones de los consultores. |
| SSEI | Servicio de Salvamento y Extinción de Incendios del aeropuerto. |
| UEP | Unidad Ejecutora del Programa, dependiente de la Gerencia General de CEPA. |
| Valor planificado | Costo presupuestado del trabajo programado hasta una fecha. |
