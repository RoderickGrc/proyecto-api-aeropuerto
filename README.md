# proyecto-api-aeropuerto

Proyecto de la asignatura API (Universidad) basado en el Programa de Modernización del Aeropuerto Internacional de El Salvador (ES-L1173), financiado por el BID.

## Contenido

- `docs/ingest/`: documentos fuente en Markdown (propuesta de préstamo, evaluación económica, análisis de costos y demanda, ROP, teoría de cambio, matriz de resultados y plan de gestión ambiental y social).
